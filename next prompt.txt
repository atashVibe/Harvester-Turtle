## Current formula rules

These formulas were intentionally changed and must not be reverted.

```text
Shares = Invested Amount ÷ Bought Price

Current Value = Shares × Current Price

Profit = Current Value − Invested Amount

Harvested Price = Bought Price × (1 + Growth Goal)

Potential Harvest Cash = Profit × Harvest Percentage
```

Harvested Price must depend only on

- Bought Price
- Growth Goal

It must not depend on Invested Amount or Minimum Cash.

Harvest Cash uses the user’s real position and Invested Amount.

Show Harvest Cash and set Action to Harvest only when

```text
Current Price ≥ Harvested Price
and
Potential Harvest Cash ≥ the user-entered Minimum Cash
```

Minimum Cash is entered by the user. It is a threshold for actual Harvest Cash based on the user’s Invested Amount.

Do not restore the older formula that used Invested Amount to calculate Harvested Price.

## Price updates

The app does not use a repeating two-minute timer.

Prices update once when the page opens. The user refreshesreloads the page to request another update.

The Twelve Data free plan currently allows

- 8 API credits per minute
- 800 API credits per day

All phones and browsers use the same Twelve Data API key, so they share one allowance.

With approximately 20 stocks, one full refresh costs about 20 credits.

Current updater behavior

- Requests up to eight symbols per group.
- Progress advances as individual responses arrive.
- Waits only until the start of the next clock minute—not a fixed 65 seconds.
- If the minute allowance was already used, it says
  `Price service limit reached. Retrying…`
- It retries the same rejected group once.
- If the service remains unavailable, it stops instead of cycling through all stocks at `0 of 20`.
- It detects a daily-limit message separately.
- Existing prices are always preserved.
- Successful top status remains
  `Updated on [time]`
- The status should not say “Updated 8 of 10” at the top.

The daily free allowance resets at midnight UTC, approximately 500 PM Pacific during daylight-saving time.

Do not change this updater unless I ask about it. If modifying it, preserve the progress behavior and error explanations.
